# Diretrizes TUI

Layout compacto, hierarquia clara, foco visível e navegação integral por teclado. Exibir atalhos quando houver espaço. Adaptar cores às capacidades do terminal; não presumir true color. Tratar resize, terminal estreito, mensagens longas e restauração ao sair. Não bloquear loop de eventos com operações HTTP/SQL. Confirmar operações destrutivas e `EXPLAIN ANALYZE`.
